This repository contains learning projects completed as part of the  
**IBM Data Science Professional Certificate** on **Coursera**.

hands-on experience with data analysis, visualization, SQL, and machine
learning using Python.

- Pandas, NumPy
- Matplotlib, Seaborn
- SQL
- Scikit-learn
- Jupyter Notebook
